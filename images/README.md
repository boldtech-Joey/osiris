# images

Photographs used on the site.

- `kit-cover.avif` — full-bleed cover for Kit (`kit.html`). Spans the viewport
  at roughly 72vh, cropped from the centre, with the page title laid over it.
  Keep the subject off the extreme edges and away from the middle, where the
  title sits. Replace the file in place to change the cover, keeping the name,
  and update `width`/`height` on the `<img>` if the ratio changes.
